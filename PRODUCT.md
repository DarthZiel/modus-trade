# Модус Трейд · Фидбек

## Platform
web — адаптивный сайт и Telegram Mini App.

## Product
Отдельный сервис обратной связи сотрудников группы «Модус Трейд».
Источник требований: MVP_SPEC.md. Пользователи: сотрудник, ответственный,
координатор. Основной цикл: обращение → назначение → обсуждение → решение
или эксперимент → результат → подтверждение автора.

## Brand commitments
Пользователь подтвердил самостоятельную айдентику сервиса «Модус Трейд Фидбек».
Дизайн должен отличаться от типовых интерфейсов хакатона. Использовать shadcn/ui
и Impeccable. Сохранять русскоязычные сценарии и все функции MVP.

## Stack
React 19, TypeScript, Vite; FastAPI и PostgreSQL. Запуск и проверки: README.md.

## Constraints
Именные обращения, закрытый доступ по приглашению, разграничение ролей.
ИИ предлагает текст только с подтверждением. Отсутствие ответа не закрывает
обращение. Мобильный кабинет должен работать внутри Telegram.
