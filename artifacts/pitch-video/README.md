# Modus Feedback — короткий питч

Референс: `Grand_Support_Copilot_V2_1080p.mp4` в корне проекта. Заимствована композиционная логика: проблема → продукт → интерфейс → отличие → финальный тезис. Текст, оформление и кадры подготовлены для Modus Feedback.

- `Modus-Feedback-pitch-1080p.mp4` — итоговый MP4, 1920×1080, 24 fps, H.264/AAC; русская синтетическая озвучка и встроенные субтитры.
- `storyboard.json` — сценарий и дикторский текст, 9 сцен.
- `subtitles-ru.srt` — отдельные субтитры.
- `manifest.json` — хронометраж сцен.
- `assets/` — снимки текущего локального интерфейса с демонстрационными данными; обращения не отправлялись и не закрывались.
- `render.py` — сборка через Pillow, Piper и FFmpeg. Шрифт Golos Text и его лицензия находятся в соседнем `../demo-video/`.

Для повторной сборки нужны Python-пакеты `piper-tts`, `pillow`, установленный FFmpeg с libass и модель Piper `ru_RU-irina-medium` с JSON-конфигурацией. Модель берётся из репозитория `rhasspy/piper-voices` на Hugging Face и по умолчанию размещается в `/tmp/modus-pitch-irina.onnx`. Либо задайте путь переменной `MODUS_PIPER_MODEL`. Карточка модели: https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/irina/medium/MODEL_CARD . У исходного набора RHVoice в карточке указано `License: Unknown`; для публичной рекламной публикации следует заменить дорожку голосом с подходящими правами. Синтетическая дорожка предназначена для локального демонстрационного ролика.

```sh
python artifacts/pitch-video/render.py
```

Сборка использует уже подготовленные WAV и клипы. После изменения сценария удалите соответствующий WAV и клип; после изменения оформления — клип. Фоновая музыка не использовалась. Видеофрагменты и звук Grand Support не копировались. Показатели эффективности компании не заявляются.
