# Iron Tech

Отдельный статический лендинг для iron-tech.kz. Modus Feedback остаётся в
`frontend/`, лендинг не обращается к API и не требует базы данных.

## Запуск

```bash
cd landing
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5180. Если система исчерпала лимит file watchers:
`CHOKIDAR_USEPOLLING=true npm run dev`.

Проверка и сборка: `npm run build` (TypeScript + Vite).
Просмотр сборки: `npm run preview -- --host 127.0.0.1 --port 5180`.
Для публикации достаточно содержимого `dist/`; Node.js на VPS не требуется.
Dockerfile также собирает статический сайт и раздаёт его через nginx.
DNS, HTTPS и публикация на VPS в эту задачу не входят.

## Дизайн

React 19, TypeScript, Tailwind CSS 4. Button, Badge и Separator — существующие
shadcn/ui Radix Nova, скопированные в самостоятельную сборку. Их API проверены
через MCP shadcn и официальные docs. Шрифты Golos Text и Geist поставляются
локально через npm; внешних шрифтов, аналитики и сетевых виджетов нет.
Принципы Emil Kowalski: короткий отклик на нажатие, hover только для мыши,
одна входная анимация, prefers-reduced-motion, видимый focus.
